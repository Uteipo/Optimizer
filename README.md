# Optimizer
Lightweight Windows utility for real-time system monitoring (CPU, RAM, disks), TEMP junk cleaning, and startup registry management built with Python and tkinter.
# Optimizer

Простая и лёгкая утилита для мониторинга и базовой оптимизации Windows, написанная на Python с графическим интерфейсом на `tkinter`.

## Возможности

* **Обзор системы:**
  * Мониторинг использования оперативной памяти (в ГБ и процентах) в реальном времени.
  * Отображение текущей нагрузки на процессор (CPU).
  * Автоматическое определение всех подключённых локальных дисков и отслеживание занятого места.
* **Очистка мусора:**
  * Безопасное удаление временных файлов Windows из системной директории `TEMP`.
  * Автоматический пропуск файлов, занятых запущенными процессами, и подсчёт удалённых объектов.
* **Управление автозагрузкой:**
  * Чтение списка пользовательских программ из реестра Windows (`HKEY_CURRENT_USER\...\Run`).
  * Отображение актуального статуса каждой программы (`[ВКЛ]` / `[ОТКЛ]`) на основе системного раздела `StartupApproved`.
  * Включение и отключение автозапуска выбранных программ в один клик без открытия Диспетчера задач.

## Установка и запуск

### Вариант 1: Готовый `.exe` файл (для Windows)
1. Перейдите в раздел **[Releases](../../releases)** справа на странице репозитория.
2. Скачайте последнюю версию `Optimizer.exe`.
3. Запустите файл (установка Python не требуется).

### Вариант 2: Запуск из исходного кода
1. Клонируйте репозиторий или скачайте `optimizer.py`:
   ```bash
   git clone https://github.com
   cd Optimizer
   ```
2. Установите необходимую библиотеку:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите приложение:
   ```bash
   python optimizer.py
   ```

## Стек технологий

* **Python 3**
* **tkinter / ttk** — графический интерфейс пользователя
* **psutil** — сбор системных метрик (CPU, RAM, диски)
* **winreg** — работа с реестром Windows
* **os / shutil** — работа с файловой системой
